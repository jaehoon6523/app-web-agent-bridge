기술 진단

시작

첫 부탁과 프로젝트 폴더를 입력하세요. ChatGPT 대화는 자동으로 시작하며, 기존 대화를 사용하려면 URL을 입력하세요.

웹과 합의를 마치고 승인하면 Git 저장소와 첫 커밋을 자동으로 준비합니다.

저장된 대화 열기

이전 합의가 새 요구사항을 자동 승인하지 않습니다. 정확한 대화에 연결할 수 없으면 상태를 확인한 뒤 다시 시도하거나 체크를 해제해 새 대화를 시작하세요.

비워 두면 확장에서 ChatGPT 시작 탭을 찾아 사용하거나 새 탭을 엽니다. 기존 대화를 지정할 때는 해당 탭을 하나만 열어 주세요.

대상 프로젝트 · 감사 기준

미확정 전송 폐기

원래 ChatGPT 응답을 확인할 수 없을 때만 사용합니다. 자동 재전송 없이 기록을 보존하고 새 작업을 허용합니다.

작업

구현 중 Worker에 전달

현재 승인된 요구사항 안에서 질문이나 참고 정보를 전달할 수 있습니다. 요구사항·완료 기준 변경은 이 실행에 끼워 넣지 않고 새 준비 작업에서 다시 승인합니다.

감사자의 확인 질문

답변은 현재 후보에 대한 재검토 자료로 기록됩니다. 요구사항이나 완료 기준을 바꾸려면 이 실행을 중단하고 새 작업으로 합의하세요.

개입 · 결과 확인

기록은 자동 만료되지 않습니다. 종료된 작업을 삭제하면 실행 기록과 감사 근거를 복구할 수 없습니다. 적용된 프로젝트 코드는 유지됩니다.

복구 확인 후 실행 폐기

CLI 프로세스·검증 작업과 ChatGPT 생성을 직접 종료하고 대상 저장소의 변경을 확인하세요. 기록과 작업 사본은 보존되며, 이 실행은 재개하거나 적용할 수 없게 됩니다.
