준비

웹 세션과 대화하며 작업 범위와 완료 기준을 합의하세요. 승인하면 바로 구현·검증을 시작합니다.

같은 대화에서 질문에 답하고 완료 기준을 조정합니다. 승인 전에는 저장소를 변경하지 않습니다.

합의한 완료 기준

검증 방식: 코드 스냅샷 검토. 실행 테스트는 포함하지 않습니다. 최대 구현 3회, 전체 30분을 기준으로 진행합니다.

시작

첫 부탁과 ChatGPT 대화 URL을 입력하세요. 웹의 완료 기준 제안을 대화로 조정하고 승인한 뒤 구현을 시작합니다.

웹과 합의를 마치고 승인하면 Git 저장소와 첫 커밋을 자동으로 준비합니다.

수정 결과를 감사할 ChatGPT 대화의 주소입니다. 브릿지 확장이 연결된 브라우저에서 이 대화의 탭을 하나만 열어 주세요.
