# 대시보드 대화·ID UX 목표 계약

2026-11-18 KST · 제안 · 제품 승인 대기

이 기준은 [현행 구현](dashboard-conversation-as-is.md)과 [의사결정표](dashboard-conversation-decision-table.md)의 관측을 바탕으로 한다. 앞으로 보장할 동작은 모두 `검토 필요`다. 보안·운영·제품 승인 기록이 추가되면 그 범위의 실행 증거와 함께 상태를 변경한다.

확장 연결에서 새 대화 저장까지의 실제 관측, 정상·복구 상태의 조작 수, 각 개선의 독립 검증 기준은 후속 문서에 있다. [최소 조작 UX 검증](dashboard-extension-minimal-ux.md)

## 작업 유형별 선택

새 작업에서는 프로젝트의 유효한 저장 대화를 추천할 수 있다. 기본 제안은 새 대화이며 사용자가 기존 주소를 선택하면 출처를 표시한다. 이어서 작업은 이전 Run 계보를 먼저 보여주고, 프로젝트 매핑과 원본 Run URL이 모두 유효하면 각각의 출처를 표시한다. 동일 URL은 하나의 선택지에 두 출처를 표시할 수 있다. 기존 대화 사용을 명시적으로 선택하지 않으면 새 대화로 진행하는 것이 D-1 권고안이다. 대화 선택은 매 작업의 준비 승인 및 작업 계보와 독립적이다.

ID 표시·접근성 샘플, 조회 오류 상태, 회귀 시나리오의 UX 설계는 이 문서를 기준으로 시작할 수 있다. 기본 대화 우선순위, 불완전 매핑과 API 의미를 바꾸는 구현은 D-1~D-4 승인 후 진행한다. [현행과 제안의 대응](dashboard-conversation-traceability.md)
